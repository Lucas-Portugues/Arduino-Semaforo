# Semáforo Interativo com Botão

Este projeto simula um semáforo de trânsito (Vermelho, Amarelo e Verde) controlado por um botão. Toda vez que você aperta o botão, o semáforo muda para a próxima cor.

## Como Funciona?
* O circuito começa com o **LED Vermelho** aceso.
* Quando o botão é apertado, o código percebe o clique e pula para a próxima cor (**Amarelo**).
* Mais um clique e vai para o **Verde**. 
* Se apertar de novo, ele volta para o **Vermelho** e reinicia o ciclo.

## Componentes Usados
* 1x Arduino Uno
* 1x Protoboard
* 3x LEDs (Vermelho, Amarelo e Verde)
* 3x Resistores de 220 Ω (para os LEDs)
* 1x Resistor de 10k Ω (para o botão)
* 1x Botão (Pushbutton)
